# Кварта — лендинг обжарки кофе

Маленькая обжарка в Минске: партии по 5 кг, обжарка по четвергам, доставка
по пятницам. Сайт — лендинг с формой заявки (подписка / разовый заказ / вопрос).

**Стек:** Next.js 14 (App Router) · TypeScript · Tailwind CSS · Prisma ·
PostgreSQL (Neon) · деплой на Vercel.

**Живой сайт:** https://kvarta.vercel.app
**Репозиторий:** https://github.com/USERNAME/kvarta-landing

## Что делал сам, а что ИИ

**Сам (без ИИ):**
- Архитектура проекта и структура блоков: hero → свежесть → ассортимент →
  подписка → доставка → форма → контакты.
- Концепция дизайна. Отказался от типового «hero + сетка карточек» в пользу
  журнала обжарки: таймлайн «чт → пт → сб», индикатор обжарки точками,
  monospace для технических деталей (граммовки, температуры). Палитра —
  эспрессо / терракота / кремовый вместо «премиального» глянца.
- Схема БД (`Lead` с UTM-полями), логика антидубля (проверка в Postgres,
  не localStorage — см. ниже), нормализация телефона.
- Валидация беларусского номера: `+375 (17|25|29|33|44) XXX-XX-XX`.
- Атрибуция: UTM + referrer + landingPage, закрепляются за первым визитом
  в localStorage. Менеджер видит, откуда пришёл клиент.
- Обработка ошибок на фронте: неверный телефон → подсказка под полем;
  ошибка сервера → понятный текст + телефон
